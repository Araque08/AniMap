🐾 AniMap

<p align="center">
  <strong>Aplicación móvil para el reporte, búsqueda y localización de mascotas perdidas.</strong>
</p>

📖 Descripción

AniMap es un proyecto desarrollado como parte del programa de Ingeniería de Software de la Universidad Manuela Beltrán.

La aplicación busca apoyar a la comunidad en los procesos de búsqueda de mascotas perdidas mediante una plataforma móvil que centraliza el registro de mascotas, reportes de pérdida, avistamientos, geolocalización y notificaciones.

El sistema permite que los usuarios registren sus mascotas y, en caso de pérdida, publiquen un reporte con información relevante y ubicación. Otros usuarios pueden consultar estos reportes y registrar avistamientos que ayuden a localizar al animal.

El proyecto está planteado inicialmente para Bogotá D.C., Colombia.

🎯 Objetivo

Desarrollar una aplicación móvil que facilite el reporte y búsqueda de mascotas perdidas, utilizando herramientas de geolocalización, mapas, notificaciones y gestión de información para conectar a los propietarios con usuarios que puedan aportar información sobre posibles avistamientos.
